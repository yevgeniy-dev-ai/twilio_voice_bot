\# Real-Time Telephony AI Voice Agent via WebSockets (Блок 3)



Третий, флагманский проект из серии разработки голосовых ИИ-систем. Проект переводит обработку звонков на принципиально новый уровень — \*\*стриминг аудиопотока в реальном времени\*\* с интеграцией облачной телефонии Twilio API.



\## 📝 Описание архитектуры

В отличие от мессенджеров, где сообщения обрабатываются файлами, данный сервис разворачивает асинхронный WebSocket-сервер. Он подключается к телефонной линии Twilio Voice Streams и «на лету» обрабатывает входящие бинарные аудио-чанки от клиента, обеспечивая минимальную задержку ответа (Latency < 1.5s).



\### Ключевые инженерные фичи:

1\. \*\*Low-Latency WebSockets\*\*: Двусторонний неблокирующий обмен данными (`FastAPI` + `uvicorn`) для непрерывной трансляции звука из трубки прямо в ИИ-пайплайн.

2\. \*\*On-the-Fly Audio Transcoding\*\*: Реализован конвертер звука в оперативной памяти. Он преобразует входящий телефонный поток `Mulaw (8kHz, mono)` в стандартный контейнер `WAV PCM (16kHz)` для распознавания моделью Whisper, а также выполняет обратную компиляция MP3 от ElevenLabs в сырой телефонный формат `Mulaw` через FFmpeg.

3\. \*\*Automated Mock Testing\*\*: Создан автономный скрипт-симулятор `test\_stream.py` для комплексного нагрузочного тестирования WebSocket-соединения. Он имитирует поведение серверов Twilio, позволяя полностью отлаживать логику ИИ локально и бесплатно, обходя ограничения триал-тарифов сотовых операторов в СНГ.



\## 🛠️ Технологический стек



| Компонент | Технология | Описание |

| :--- | :--- | :--- |

| \*\*Backend \& Стриминг\*\* | FastAPI / WebSockets / Uvicorn | Асинхронное ядро сервера и скоростные каналы связи |

| \*\*Телефония\*\* | Twilio Voice API / TwiML (XML) | Маршрутизация звонков и интеграция с телефонной сетью |

| \*\*Модель ИИ (LLM)\*\* | Groq API (Llama 3.3 70B Versatile) | Ультра-быстрая генерация контекстных ответов (Inference < 0.4s) |

| \*\*Распознавание (ASR)\*\* | OpenAI Whisper (Local, base model) | Локальное неблокирующее извлечение текста из аудиопотока |

| \*\*Синтез речи (TTS)\*\* | ElevenLabs API (Flash v2.5 Multilingual) | Мультиязычный реалистичный синтез голоса (Roger) |

| \*\*Аудио-движок\*\* | FFmpeg / `audioop` / `wave` / `io` | Низкоуровневая обработка, ресемплинг и кодирование байт |



\## 🚀 Инструкция по локальному запуску



1\. Установите все необходимые асинхронные зависимости:

```bash

pip install -r requirements.txt

```



2\. Настройте конфигурационный файл `.env` в корне папки проекта:

```env

GROQ\_API\_KEY=your\_groq\_api\_key\_here

ELEVENLABS\_API\_KEY=your\_elevenlabs\_api\_key\_here

TWILIO_ACCOUNT_SID=api\_key\_here

TWILIO_AUTH_TOKEN=api\_key\_here

```



3\. Запустите основной WebSocket-сервер:

```bash

python main.py

```



4\. Для проведения автоматического теста без затрат на сотовую связь, положите любой рабочий файл `test.wav` в корень папки и запустите локальный эмулятор во втором окне терминала:

```bash

python test\_stream.py

```
